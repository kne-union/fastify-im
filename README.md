# fastify-im

### 描述

通用IM即时通讯Fastify插件，支持WebSocket消息、单聊群聊、系统消息推送、离线通知、身份认证与角色权限

### 关键词

fastify, im, websocket, chat, messaging, instant-messaging, group-chat, system-message, notification

### 安装

```shell
npm i --save @kne/fastify-im
```
